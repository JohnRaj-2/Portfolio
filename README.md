# 🚀 Developer Portfolio Website

A modern, visually stunning, and fully responsive personal portfolio website built using **HTML, CSS, and JavaScript** to showcase professional experience, technical skills, projects, and achievements.

## 🌐 Live Demo

🔗 **Deployed Website:** [View Portfolio](https://portfolio-lemon-tau-70.vercel.app/)

## ✨ Features

* Fully responsive design (Mobile, Tablet & Desktop)
* Modern UI with beautiful color palette
* Smooth animations and interactive effects
* Professional experience & education
* Technical skills showcase
* Interactive project gallery
* GitHub, LinkedIn & LeetCode links
* Downloadable Resume
* Contact section
* Mobile-friendly navigation

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)
